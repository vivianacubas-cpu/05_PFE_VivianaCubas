# S04 - Catálogo de Películas

Aplicación Angular correspondiente a la **Opción 2: Catálogo de Películas**.

## Conceptos demostrados

- Interpolación `{{ }}`
- Property Binding `[disabled]`
- Event Binding `(click)`
- Two-Way Binding `[(ngModel)]`
- Directiva condicional `@if`
- Directiva de repetición `@for`
- Clases dinámicas `[class]`

## Restricciones respetadas

- Datos únicamente en memoria dentro de los componentes.
- Sin base de datos.
- Sin APIs externas.
- Sin backend.
- Sin servicios.
- Sin CRUD complejo.
- Sin Angular Material.
- Sin Bootstrap.
- Sin librerías visuales externas.
- Animaciones realizadas con CSS.

## Ejecución

```bash
npm install
ng serve -o
```
