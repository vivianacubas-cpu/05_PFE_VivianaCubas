# Atelier de Autores

Aplicación Angular para gestionar la entidad maestra **Autores** mediante la API REST pública de DummyJSON.

## Requisitos académicos demostrados

- Angular + TypeScript
- HttpClient
- API REST pública
- CRUD: GET, POST, PUT y DELETE
- Componentes Angular
- `@Input()` y `@Output()`
- `EventEmitter`
- `[(ngModel)]`
- `@for`
- Formulario de registro y edición
- Listado dinámico de autores
- Diseño responsive y animaciones suaves

## Ejecutar

```bash
npm install
ng serve
```

Luego abrir la dirección que indique Angular en la terminal.

> Nota: DummyJSON simula POST, PUT y DELETE. La aplicación actualiza el listado local inmediatamente para que el CRUD pueda demostrarse durante la presentación.
