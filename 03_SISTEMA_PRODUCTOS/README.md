# S03 - Sistema de Productos

CRUD desarrollado con Angular 19+ y datos locales.

## Estructura
Se conserva la estructura original de componentes:
- components/navbar
- components/producto-formulario
- components/producto-lista
- components/producto-card

## Funciones
Crear, visualizar, editar y eliminar productos. Incluye 5 registros iniciales, formulario, diseño morado y animaciones.

```bash
npm install
ng serve -o
```
